设计原则

所有 TokenDance 工具共同遵守的四条约定。

  1. 本地优先

    记录默认保存在你的设备上，离线可用，不依赖云端账号。

  2. 无广告，无追踪

    不嵌入广告 SDK，不出售或共享个人数据，不做跨应用跟踪。

  3. 一个工具，一件事

    功能保持克制，打开即用，把复杂度留在开发者这一侧。

  4. 长期维护

    由同一位开发者持续迭代，问题与建议都能直接得到回复。

常见问题

TokenDance 是什么？

TokenDance 是独立开发者 Tony 维护的软件工具集合，每个工具解决一个具体问题，目前包括 every15min、守守 Goldie，以及开发中的 Code Buddy 和广告拦截助手。

我的数据保存在哪里？

TokenDance 的工具以本地存储为默认设计，every15min 和守守 Goldie 的记录保存在你自己的设备上，不需要注册账号。具体以各产品页面的隐私说明为准。

守守 Goldie 可以代替医生的建议吗？

不可以。守守 Goldie 是记录与提醒工具，帮助你整理用药和发作情况，方便复诊时与医生沟通，不提供诊断或治疗建议。
