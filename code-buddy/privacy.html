简要说明

Code Buddy 不收集任何数据。它读到的日志和算出来的数字，都只留在你的 Mac 上。

读取哪些文件

Code Buddy 只读取你在 App 里授权的文件夹（通常是 ~/.claude 和 ~/.codex）中，Claude Code 和 Codex 自己写下的会话日志，用来判断它们现在的状态、统计 token 用量和估算费用。读取是只读的：Code Buddy 不会改动这些文件，也读不到授权文件夹以外的内容。

不联网

Code Buddy 运行在 macOS 的 App 沙盒里，没有联网权限，不连接任何服务器。没有账号，也没有统计、广告或第三方 SDK。

保存在本机的内容

你的设置（是否显示桌面浮窗、浮窗大小和位置、是否登录时启动）和授权文件夹的访问凭证，只保存在这台 Mac 上 Code Buddy 自己的沙盒文件夹里。

精确状态

“精确状态”默认关闭。开启后，Claude Code 的 hook 会把事件逐行追加到 ~/.claude/buddy/events.jsonl。这些 hook 由你自己（或你让 Claude Code）加进 ~/.claude/settings.json，只调用系统自带的 sh，不联网。这个文件只在你的 Mac 上，Code Buddy 只读取它。

我们能看到什么

什么也看不到。我们收不到、也读不到你的日志、用量和设置。

删除

Code Buddy 保存的内容都在 ~/Library/Containers/com.taopan.codebuddy。删除 App 和这个文件夹，它在这台 Mac 上留下的内容就全部清除了。开启过精确状态的话，先在设置 → 精确状态里点“复制关闭指令”，粘贴给 Claude Code 移除 hook（也可以自己从 settings.json 里删掉），再删除 ~/.claude/buddy 文件夹。

本网站

以上内容只针对 App。本网站（tokendance.life）使用 Google Analytics 和 Cloudflare Web Analytics 统计访问量和访问来源。两者都不在你的浏览器里保存 Cookie，Google Analytics 已关闭 Google 信号和广告个性化。我们只看汇总数据，不会用来识别任何人。

政策变更

如本政策发生变更，新版本会发布在此页面，并更新生效日期。

The short version

Code Buddy collects no data. The logs it reads and the numbers it works out stay on your Mac.

What it reads

Code Buddy reads only the session logs that Claude Code and Codex write in the folders you grant in the app (usually ~/.claude and ~/.codex), to show what those tools are doing, count tokens and estimate spend. Access is read-only: Code Buddy never changes these files and cannot read anything outside the folders you granted.

No network access

Code Buddy runs in the macOS App Sandbox without network access and connects to no server. There is no account, no analytics, no advertising and no third-party SDK.

What stays on your Mac

Your settings (whether the desktop face is shown, its size and position, whether it opens at login) and the access grants for your folders are kept only on this Mac, in Code Buddy's own sandbox folder.

Precise Status

Precise Status is off by default. When you turn it on, Claude Code's hooks append each event as one line to ~/.claude/buddy/events.jsonl. You add these hooks to ~/.claude/settings.json yourself (or ask Claude Code to); they only call the system's built-in sh and never go online. The file stays on your Mac, and Code Buddy only reads it.

What we can see

Nothing. We never receive and cannot read your logs, usage or settings.

Removing it

Everything Code Buddy stores is in ~/Library/Containers/com.taopan.codebuddy. Delete the app and that folder, and nothing it kept is left on your Mac. If you turned on Precise Status, first open Settings → 精确状态 (Precise Status), click 复制关闭指令 (copy the turn-off request) and paste it to Claude Code to remove the hooks (or delete them from settings.json yourself), then delete the ~/.claude/buddy folder.

This website

Everything above is about the app. This website (tokendance.life) uses Google Analytics and Cloudflare Web Analytics to count visits and see where they come from. Neither stores cookies in your browser, and Google signals and ad personalization are turned off in Google Analytics. We only look at aggregate numbers and never use them to identify anyone.

Changes
