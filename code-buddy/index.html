中文 English

使用前提

  • macOS 14 或更新版本
  • 这台 Mac 上在用 Claude Code 或 Codex 命令行工具
  • 界面目前只有简体中文

开始使用

  1. 打开 Code Buddy，欢迎窗口会请你授权日志文件夹：Claude Code 是 ~/.claude，Codex 是 ~/.codex。授权窗口已经打开在对应的文件夹里，直接点“授权”就行。没装的那个可以跳过，之后也能在设置里授权。
  2. 点菜单栏里的小圆脸打开面板，看状态、用量和花费。面板里的“打开设置...”进入设置，“退出 Code Buddy”退出。

表情是什么意思

  • 干活：助手在思考、调用工具、改代码
  • 等你：助手停下来等你确认（需要开启精确状态）
  • 完成：这一轮做完了，可以回来看结果
  • 出错：请求没有成功
  • 待机、睡觉：最近没有动静

常见问题

面板里没有数字

用量来自 Claude Code 和 Codex 写在本机的会话日志。请在设置 → 数据来源里确认对应的文件夹显示“已授权”，并且这台 Mac 上用过这些工具。

提示“需要授权整个 ~/.claude 文件夹”

你授权的是 ~/.claude 里面的 projects 文件夹。用量照常能看，但精确状态要用到 ~/.claude 本身：在设置 → 数据来源里重新授权，选 ~/.claude。

怎么让它在等我确认时提醒我

开启精确状态：设置 → 精确状态 → 复制开启指令，粘贴给 Claude Code，让它帮你把 hook 加进 ~/.claude/settings.json；也可以点“打开 settings.json”自己粘贴进去。之后新开的会话生效。这些 hook 只用系统自带的 sh 把事件写进 ~/.claude/buddy/events.jsonl，不联网。Code Buddy 自己不会改动 settings.json。

怎么关掉精确状态

设置 → 精确状态 → 复制关闭指令，同样粘贴给 Claude Code；或者自己从 settings.json 里删掉命令中含有 buddy/events.jsonl 的 hook。

费用准吗

费用按公开的 API 价格估算，不是账单。如果你用的是订阅套餐，只能当作参考。

桌面浮窗

设置 → 桌面浮窗：显示或隐藏，大、中、小三种尺寸，拖到哪里都行。“预览所有表情”会把六种表情播一遍。

开机自动启动

设置 → 通用 → 登录时启动。默认关闭。

卸载

在面板里点“退出 Code Buddy”，再把它从“应用程序”拖到废纸篓。开启过精确状态的话，先按上面的方法关掉，再删除 ~/.claude/buddy 文件夹。

隐私

Code Buddy 不收集任何数据，没有联网权限。详见隐私政策。

Requirements

  • macOS 14 or later
  • Claude Code or Codex (the command-line tools) in use on this Mac
  • The interface is in Simplified Chinese for now

Getting started

  1. Open Code Buddy. The welcome window asks you to grant the log folders: ~/.claude for Claude Code and ~/.codex for Codex. The panel already opens in the right folder, so just click 授权 (Grant). Skip the one you don't use; you can grant it later in Settings.
  2. Click the face in the menu bar to see status, usage and spend. 打开设置... opens Settings and 退出 Code Buddy quits.

What the faces mean

  • Working: the agent is thinking, calling tools or editing code
  • Waiting: the agent needs your approval (with Precise Status on)
  • Done: the turn is finished, come back and look
  • Error: a request failed
  • Idle, asleep: nothing going on lately

Common questions

The panel shows no numbers

Usage comes from the session logs Claude Code and Codex write on your Mac. In Settings → 数据来源 (Data sources), check that the folder says 已授权 (granted), and that you have used those tools on this Mac.

It says the whole ~/.claude folder is needed

You granted the projects folder inside ~/.claude. Usage still works, but Precise Status needs ~/.claude itself: grant again in Settings → 数据来源 (Data sources) and pick ~/.claude.

How do I get told when the agent is waiting for me?

Turn on Precise Status: Settings → 精确状态 (Precise Status) → 复制开启指令 (copy the turn-on request), then paste it to Claude Code and let it add the hooks to ~/.claude/settings.json, or click 打开 settings.json and paste them in yourself. New sessions pick it up. The hooks only use the system's built-in sh to write events to ~/.claude/buddy/events.jsonl and never go online. Code Buddy itself never changes settings.json.

How do I turn Precise Status off?

Settings → 精确状态 (Precise Status) → 复制关闭指令 (copy the turn-off request) and paste it to Claude Code, or delete the hooks whose command contains buddy/events.jsonl from settings.json yourself.

How accurate is the spend?

It is estimated from public API prices and is not a bill. If you are on a subscription plan, treat it as a guide.

Desktop face

Settings → 桌面浮窗 (Desktop face): show or hide it, pick one of three sizes, and drag it anywhere. 预览所有表情 (Preview all expressions) plays all six faces.

Open at login

Settings → 通用 (General) → 登录时启动 (Open at login). It is off by default.

Uninstalling

Click 退出 Code Buddy in the panel, then drag the app from Applications to the Trash. If you turned on Precise Status, turn it off as above first, then delete the ~/.claude/buddy folder.
