How it works

When it needs you, it looks at you.

Stop babysitting the terminal. Code Buddy reads your agent’s session logs and changes its face the moment something happens. Glance up, and you know whether to switch back.

    Several agents at once

    Four agents. One face.

    Run Claude Code in one project and Grok in another. The face always shows the one that needs you most, the menu bar shows how many are busy, and every session is listed with its project and context. Runs started by scripts and bots are listed apart and don’t move the face.

    Help

    Setup, what the faces mean, and answers to common questions.

    Questions or ideas? Email tonybingpoon@gmail.com. I read and answer every message myself.

    Requirements

    • macOS 14 or later
    • Claude Code (terminal, Claude desktop app or VS Code extension), Codex (CLI, desktop app or IDE extension), Grok or Cursor in use on this Mac. Code Buddy reads local sessions on this Mac only; cloud sessions don’t show up.
    • English, or Simplified Chinese when your Mac is set to Chinese

    Getting started

    1. Open Code Buddy. The welcome window has a Grant… button for each tool: ~/.claude for Claude Code, ~/.codex for Codex, ~/.grok for Grok and ~/.cursor for Cursor. The folder picker already opens in the right folder, so just click Grant. Skip any you don’t use; you can grant them later in Settings. Click Get Started when you’re done.
    2. Click the face in the menu bar to see status, usage and spend. Settings… opens Settings, Show/Hide Desktop Face toggles the face on your desktop, and Quit Code Buddy quits.

    What the faces mean

    • Working: the agent is thinking, calling tools or editing code
    • Waiting: the agent needs your approval (with Precise Status on)
    • Done: the turn is finished, come back and look
    • Error: a request failed
    • Idle, Asleep: nothing going on lately

    Common questions

    The panel shows no numbers

    Usage comes from the session logs Claude Code and Codex write on your Mac. In Settings → Data Sources, check that the folder shows its path rather than Not granted, and that you have used those tools on this Mac.

    It says the whole ~/.claude folder is needed

    You granted only the projects folder inside ~/.claude. Usage still works, but Precise Status needs ~/.claude itself: in Settings → Data Sources, click Change… and pick ~/.claude.

    How do I get told when the agent is waiting for me?

    Turn on Precise Status: Settings → Precise Status → Copy Turn-On Request, then paste it to Claude Code and let it add the hooks to ~/.claude/settings.json, or click Open settings.json and paste them in yourself. New sessions pick it up. The hooks only use the system’s built-in sh to write events to ~/.claude/buddy/events.jsonl and never go online. Code Buddy itself never changes settings.json.

    How do I turn Precise Status off?

    Settings → Precise Status → Copy Turn‑Off Request, and paste it to Claude Code. Or delete the hooks whose command contains buddy/events.jsonl from settings.json yourself.

    How accurate is the spend?

    It is estimated from public API prices and is not a bill. If you are on a subscription plan, treat it as a guide.

    Desktop face

    Settings → Desktop Face: turn Show Desktop Face on or off, pick Small, Medium or Large, and drag the face anywhere. Preview All Expressions plays all six faces.

    Launch at login

    Settings → General → Launch at Login. It is off by default.

    Uninstalling

    Click Quit Code Buddy in the panel, then drag the app from Applications to the Trash. If you turned on Precise Status, turn it off as above first, then delete the ~/.claude/buddy folder.
