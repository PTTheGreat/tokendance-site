  1. 每 15 分钟，一个节拍

    App 和桌面小组件一直在倒数下一个整刻钟，到点就记一笔。节奏可以改成 5 到 60 分钟。

    输入 find #work，相关记录立刻筛出来。

    Code Buddy

    1. 助手在忙什么，看一眼就知道

      菜单栏里有一张小圆脸，桌面上还有个大的。看它的表情就知道助手在干活、在等你，还是做完了。

    2. 需要你的时候，它会抬头看你

      Claude Code 停下来等你批准时，小圆脸马上抬头看你，不用每分钟去翻终端。

    3. 四个助手，一张脸

      Claude Code、Codex、Grok、Cursor 可以同时开。小圆脸显示最需要你的那个，菜单栏显示有几个在忙。

    4. 用量和花费，按工具分开算

      今天、7 天、30 天的 token 和估算花费按工具分开列，还能看 Codex 额度还剩多少。Cursor 只显示状态。

      Speechless

      1. 按住，说话，松手

        在正在用的输入框里按住面板，说完松手，文字就输入在光标的位置，不用跳出 App。

      2. 平时怎么说，就怎么说

        一句话里可以中英混说。口头禅和说错重来的部分会去掉，标点会补好。它不是每次都对。

      3. 上滑发送，或者取消

        按住时上滑：左边取消，右边松手就发，要输入框有发送键。点 ABC 切到普通打字。

      4. AI 服务，用你自己的

        用自己的 API Key 添加服务。你说的内容只发给你添加并同意的服务，你打的字不会发送。

      关于

      应用里不放广告 SDK，不做跟踪，不需要在我这里注册，你留在应用里的内容我都看不到。every15min、守守和 Code Buddy 的记录只在你的设备上。Speechless 例外：你同意之后，它会把你说的话发给你添加的 AI 服务，详见它的隐私政策。

      需要注册账号吗？
      我这边没有账号系统。every15min、守守和 Code Buddy 都不需要账号；Speechless 需要你选的 AI 服务的 API Key，也就是要有那个服务的账号。
      数据只存在我的设备上吗？
      every15min、守守和 Code Buddy 是这样。Speechless 例外：你在 App 里同意之后，说的内容会发给你添加的 AI 服务。发什么、发给谁，见它的隐私政策。
      守守能代替医生吗？
      不能。它帮你把情况记清楚，治疗请听医生的。
