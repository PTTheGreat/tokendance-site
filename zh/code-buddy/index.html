    使用前提

    • macOS 14 或更新版本
    • 这台 Mac 上在用 Claude Code（终端、Claude 桌面 App 或 VS Code 扩展）、Codex（命令行、桌面 App 或 IDE 扩展）、Grok 或 Cursor。Code Buddy 只读这台 Mac 上的本地会话，看不到云端会话。
    • 界面支持简体中文和英文，跟随系统语言

    开始使用

    1. 打开 Code Buddy，欢迎窗口会请你授权日志文件夹：Claude Code 是 ~/.claude，Codex 是 ~/.codex，Grok 是 ~/.grok，Cursor 是 ~/.cursor。授权窗口已经打开在对应的文件夹里，直接点“授权”就行。没装的那个可以跳过，之后也能在设置里授权。
    2. 点菜单栏里的小圆脸打开面板，看状态、用量和花费。面板里的“打开设置...”进入设置，“退出 Code Buddy”退出。

    表情是什么意思

    • 干活：助手在思考、调用工具、改代码
    • 等你：助手停下来等你确认
    • 完成：这一轮做完了，可以回来看结果
    • 出错：请求没有成功
    • 待机、睡觉：最近没有动静

    常见问题

    面板里没有数字

    用量来自 Claude Code 和 Codex 写在本机的会话日志。请在设置 → 数据来源里确认对应的文件夹显示的是路径而不是“未授权”，并且这台 Mac 上用过这些工具。

    提示“需要授权整个 ~/.claude 文件夹”

    你授权的是 ~/.claude 里面的 projects 文件夹。用量照常能看，但要看到等你批准和用精确状态，都需要 ~/.claude 本身：在设置 → 数据来源里点“更换…”，选 ~/.claude。

    怎么让它在等我确认时提醒我

    较新版本的 Claude Code 会在自己的会话文件里记下权限确认框，Code Buddy 几秒内就能显示，不用做任何设置。 想在确认框出现的一瞬间就收到提醒，就开启精确状态：设置 → 精确状态 → 复制开启指令，粘贴给 Claude Code，让它帮你把 hook 加进 ~/.claude/settings.json；也可以点“打开 settings.json”自己粘贴进去。之后新开的会话生效。这些 hook 只用系统自带的 sh 把事件写进 ~/.claude/buddy/events.jsonl，不联网。Code Buddy 自己不会改动 settings.json。

    怎么关掉精确状态

    设置 → 精确状态 → 复制关闭指令，同样粘贴给 Claude Code；或者自己从 settings.json 里删掉命令中含有 buddy/events.jsonl 的 hook。

    费用准吗

    费用按公开的 API 价格估算，不是账单。如果你用的是订阅套餐，只能当作参考。

    桌面浮窗

    设置 → 桌面浮窗：显示或隐藏，大、中、小三种尺寸，拖到哪里都行。“预览所有表情”会在按钮旁边把六种表情播一遍，桌面浮窗也跟着变。

    开机自动启动

    设置 → 通用 → 登录时启动。默认关闭。

    卸载

    在面板里点“退出 Code Buddy”，再把它从“应用程序”拖到废纸篓。开启过精确状态的话，先按上面的方法关掉，再删除 ~/.claude/buddy 文件夹。
