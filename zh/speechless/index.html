Speechless 语音键盘 · iPhone

按住。 说话。 松手。

一个语音键盘，AI 服务用你自己的。按住面板说，松手，文字就输入在光标的位置，不用跳出正在用的 App。

准备上架中

App 免费 · iOS 17 或更新版本 · AI 服务和 API Key 由你自己添加

示例

那个 PR 我看完了，没问题，下午 merge 吧。

按住、点一下，或者上滑。

    一句话输入之后会出现。撤回是把它拿掉，重说是拿掉之后马上再录一遍。

AI 服务，用你自己的。

Speechless 只是一个键盘，本身不带 AI。你用自己的 API Key 添加一个或几个服务，再各选一个模型：一个识别，一个整理。两个可以来自不同的服务。

费用由这些服务直接向你收。我不卖 AI 用量，没有服务器，也不从任何一家拿钱。

  • OpenRouter默认，已配好推荐的模型
  • OpenAI
  • 阿里云百炼通义千问
  • 火山方舟豆包
  • 硅基流动
  • 其他兼容 OpenAI 接口的服务填地址添加

与上述公司没有关联。哪个适合你，由你来选。

你的声音会发给谁。

直接发给你选的服务。每个服务第一次使用之前，App 会写明它的名字和地址，问你同不同意。不同意就不会往那里发，打字照常能用。

你的 iPhone

用你自己的 API Key，把你说的内容直接发出去，中间没有我的服务器。

你选来识别的服务

收到录音：说完时发送，中间停顿时也可能提前发，让你少等一会儿。同时带上词典里的词作为提示。

你选来整理的服务

收到识别出的文字，同时带上词典里的词作为提示。

用 OpenRouter 时

默认的识别模型是 ElevenLabs Scribe v2 和 AssemblyAI Universal‑3.6 Pro，前一个慢的时候再用 Mistral AI 的 Voxtral Small Transcribe 3 备用；整理用 DeepSeek V4.1 Flash 或 GLM‑5.3 Flash，由 OpenRouter 从符合要求的服务商里选一家运行。

不管你选哪个模型，每次请求都要求零数据保留、不收集数据。少数例外写在隐私政策里。OpenRouter（美国）会保留时间、模型、token 数这类元数据，用来计费。

用其他服务时

你说的内容从 iPhone 直接发给那个服务，适用它自己的条款和隐私政策。Speechless 没法在那里设置零保留：它保留多久、怎么使用，是你和那个服务之间的事。处理数据的地方可能在其他国家或地区。各个服务怎么处理，见隐私政策里的链接。

只存在你的 iPhone 上

  • API Key，每个服务一个，存在 iOS 钥匙串里，只发给它所属的服务
  • 设置，以及词典本身
  • 最近 30 条说过的内容，只有文字
  • 还没识别出来的句子的录音
  • 技术日志，没有你说的话，留 14 天

我这边收不到

我收不到录音、文字、Key 和使用数据。App 里没有统计、广告、跟踪，也没有第三方 SDK。你用 ABC 键盘打的字不保存、不记录、不发送。

完整内容见隐私政策。

使用帮助

怎么设置、怎么用，以及常见问题。

遇到问题或有建议，请写信到 tonybingpoon@gmail.com，每封我都会亲自看、亲自回。

使用前提

  • iPhone，iOS 17 或更新版本。界面有简体中文和英文。
  • 用语音：要联网，用自己的 API Key 添加一个 AI 服务，给键盘打开“允许完全访问”，允许使用麦克风，并在 App 里同意把说的内容发给那个服务。
  • 用 ABC 键盘打字：不需要别的。不联网、不开完全访问、没有 Key 都能用。
  • 上架地区：正在准备上架 App Store。刚开始不在中国大陆和欧盟提供。

怎么设置

  1. 打开 Speechless App，允许使用麦克风。
  2. 在 设置 › 通用 › 键盘 › 键盘 › 添加新键盘 里选 Speechless，再点进 Speechless，打开“允许完全访问”。
  3. 在 App 的“AI 服务”里添加一个服务，粘贴它的 API Key。App 会写明这个服务的名字和地址，问你同不同意把说的内容发过去。不同意也能打字。
  4. 同意之后，App 会读取这个服务的模型列表，并用你的 Key 各试一次识别（一秒静音）和整理（一句简短的示例），让你知道两样都能用。这两次小测试里没有你说的内容。然后选一个模型识别、一个模型整理；用 OpenRouter 的话，推荐的模型已经配好。
  5. 点一个输入框，长按地球键，选 Speechless。

选哪个服务

  • 要有那个服务的账号和 API Key。OpenRouter 的条款要求账号持有人是成年人，其他服务有各自的规定。
  • 默认是 OpenRouter。用它时，App 只列出 OpenRouter 标明零保留的模型。
  • 也可以添加 OpenAI、阿里云百炼（通义千问，北京或新加坡地域）、火山方舟（豆包，识别用的是能听声音的通用模型，不是专门的语音模型）、硅基流动（中国站或国际站），或者填 https 地址添加其他兼容 OpenAI 接口的服务。
  • 识别和整理可以用不同的服务。
  • 你所在的地区能不能用、价格、对你所说语言的效果、速度、数据条款，每个服务都不一样。添加之前请看它自己的条款和隐私政策。
  • 只有用 OpenRouter 时会要求零数据保留。用其他服务时，以那个服务的条款为准。

怎么用

  • 按住面板说话，松手结束。或者点一下开始，再点一下结束。
  • 按住上滑：左边取消；右边松手就发，输入框的回车键是发送、搜索或前往时才有。
  • 一句话输入之后，“撤回”可以把它拿掉，“重说”可以重新说一遍。
  • 长按标点键选其他标点。长按空格左右滑动移光标。长按删除连续删。
  • 一次最长录 3 分钟。点一下开始的，一分钟没听到说话会自己停。
  • 人名、产品名可以填进 App 里的词典，说话时会作为提示一起发送。

常见问题

需要注册账号吗

我这边没有账号。用语音需要你选的 AI 服务的 API Key，也就是要有那个服务的账号。打字两样都不需要。

语音用不了

看看麦克风允许了没有、“允许完全访问”打开了没有、手机能不能上网，以及 App 里有没有添加能用的服务和 Key、有没有同意、有没有选好模型。都没问题的话，看看那个服务的账号里还有没有余额。

为什么要“允许完全访问”

不打开的话，iOS 不给键盘网络和麦克风，语音就用不了。ABC 打字不需要它。打开之后，Speechless 同样不保存、不记录、不发送你打的字。

它会在后台偷听吗

不会。只在你说话输入时录音，这时系统的麦克风指示和键盘自己的动画都会显示。一次最长录 3 分钟；点一下开始的，一分钟没听到说话会自己停。

要花钱吗

App 免费，没有内购和广告。你添加的 AI 服务用了多少，由它们直接向你收费。我不卖 AI 用量，也不从任何一家拿钱。

有词听错了

会有这种时候。点“撤回”或“重说”，或者手动改。如果总是听错同一个名字，把它填进 App 里的词典。

右下角显示“换行”，不是“发送”

有些 App 的发送是它自己的按钮，键盘按不到，这里就显示“换行”。请点那个 App 自己的按钮。

音乐停了

录音的时候，正在播放的音乐会暂停。

有点慢

要等多久，取决于你的网络、你选的服务和模型。

密码框里没有 Speechless

密码框里，iOS 会把第三方键盘换成自带的。有些 App 也不允许第三方键盘。

有一句没出来

没识别出来的录音会先留在手机上，可以重试。最近 30 条说过的内容，在 App 里能看到文字。

怎么让它不再发送

在 Speechless App 的“AI 服务”里点那个服务，再点“不再同意”，之后不会再往那里发送任何内容。每个服务都可以随时单独撤回，打字照常能用。

怎么删除数据

在 App 里，“清空”会删掉最近说过的内容；“隐私”里的“清除全部数据”会删掉 Key、词典、最近的内容、录音和日志。在“AI 服务”里删除一个服务，它的 Key 也会删掉。

卸载

先在 App 的“隐私”里点“清除全部数据”，再删除 App。删除 App 会一并删掉它存的内容，但 iOS 可能会保留钥匙串里的东西，API Key 就存在那里。你也可以到那个服务的账号里把 Key 删掉。

隐私

你同意之后，Speechless 会把你说的内容发给你添加的 AI 服务；你打的字不会发送。详见隐私政策。
