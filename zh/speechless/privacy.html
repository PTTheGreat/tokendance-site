Speechless 语音键盘 · iPhone 和 Mac

隐私政策

适用于 iPhone 上的 Speechless App 和它的键盘，以及 Mac 版 · 生效日期 2026 年 11 月 25 日

简要说明

  • Speechless 是一个语音键盘，AI 服务用你自己的：你用自己的 API Key 添加一个或几个服务。说话输入时，数据会离开 iPhone：录音发给你选来识别的服务，识别出的文字发给你选来整理的服务，词典里的词作为提示一起发送。只有你在 App 里同意某个服务之后才会发给它，只用来把你说的话变成文字。
  • 用默认的 OpenRouter 时，每次请求都要求零数据保留、不训练。用其他服务时，以那个服务自己的条款为准，Speechless 没法在那里设置零保留。
  • 你用 ABC 键盘打的字，不保存、不记录、不发送。
  • 我不提供 AI 服务，没有服务器，收不到录音、文字、Key 和使用数据。App 里没有统计和第三方 SDK，没有跟踪，没有广告，也不出售数据。

谁做的

Speechless 由独立开发者 Tao Pan 制作，以 TokenDance 的名义发布（也就是本站的 Tony）。本政策里的“我”指 Tao Pan，“Speechless”指这个 App 和它的键盘。

发送什么，什么时候发

添加哪些服务由你选：OpenRouter、OpenAI、阿里云百炼（通义千问）、火山方舟（豆包）、硅基流动，或者填 https 地址添加其他兼容 OpenAI 接口的服务。每个服务使用之前，App 会写明它的名字和地址，征求你的同意。你没有添加、没有同意的服务，收不到你说的任何内容。一个都不同意的话，语音不会开，打字照常能用。

同意之后，每次说话输入时，这些内容会从 iPhone 直接发给你选的服务：

  • 你说的那段录音，发给你选来识别的服务。说完时发送；中间停顿时也可能提前发，让你少等一会儿。取消会丢掉录音，但已经发出去的部分收不回来。
  • 识别出来的文字，发给你选来整理的服务。
  • 你词典里的词，跟着一起发，作为人名和术语的提示。
  • 你在那个服务的 API Key，让它知道是谁的请求。和任何联网一样，那个服务也会看到你的 IP 地址。请求里还可能带上这个 App 的名字。

你同意一个服务之后，App 会马上读取它的模型列表，并用你的 API Key 各试一次识别（一秒静音）和整理（一句简短的示例），让你知道两样都能用。这些测试请求里没有你说的内容。之后键盘出现时，可能会先和你选的服务建好连接，这个请求带着 API Key，没有录音，也没有文字。

以上连接都使用 HTTPS。

这些只有一个目的：把你说的话变成文字，也就是识别语音、找出听错的词、去掉口头禅和说错重来的部分、补好标点。

用 OpenRouter 时

OpenRouter（OpenRouter, Inc.，美国）是默认的服务。用它时，App 只列出 OpenRouter 标明零保留的模型。它会收到上面列出的内容，把每次请求转给运行模型的公司，并向你收费。用默认模型时，下面这些公司会通过 OpenRouter 收到数据：

谁收到什么用来做什么
ElevenLabs（Scribe v2）录音、词典里的词把录音变成文字
AssemblyAI（Universal‑3.6 Pro）录音、词典里的词听同一段录音，用来找出听错的词
Mistral AI（Voxtral Small Transcribe 3）录音、词典里的词备用，第一个慢的时候才用
运行 DeepSeek V4.1 Flash 或 GLM‑5.3 Flash 的服务商识别出的文字、词典里的词整理文字。由 OpenRouter 从符合要求的服务商里选，不一定是做这个模型的公司

如果你在 OpenRouter 上换了别的模型，收到同样数据的就是运行那些模型的公司，要求不变。

我要求怎么保护

对 OpenRouter，以及它转发的每一家公司，我都要求给你的数据和本政策同等的保护：只用来完成这次请求，处理完不保存，不拿来训练。所以不管你选哪个模型，每个带录音或文字、发给 OpenRouter 的请求都设了 zdr: true（零数据保留）和 data_collection: deny，只会发给 OpenRouter 标明处理完不保存、不拿来训练的服务。如果没有符合要求的服务，请求会失败，不会改发到别处。

这一点依据的是 OpenRouter 的标注，我没法检查这些公司的系统。OpenRouter 自己写明了这些例外：

  • 它会检查请求里有没有儿童性虐待内容，零保留的请求也在内。被标记的内容可能会按法律要求留下来，用于审核、举报和保全。
  • 它把少数可能保留请求的端点也算作零保留：只为发现、调查和防止滥用，不用于训练（它叫“Safety Retention”）。写这份政策时只有 Google Vertex AI 一家。Speechless 每次请求都排除它，也不列出只在那里运行的模型。
  • 如果你在自己的 OpenRouter 账号里选了让它保存请求内容，这个选择对 Speechless 同样有效。

详见 OpenRouter 的零数据保留说明（英文）。OpenRouter 自己会保留请求的元数据（如时间、模型、token 数）用来计费，依据是它自己的隐私政策。这些公司处理数据时，也适用它们自己的条款和隐私政策：ElevenLabs、AssemblyAI、Mistral AI。

用其他服务时

如果你添加了别的服务，并选它来识别或整理，你说的内容会从 iPhone 直接发给那个服务，用的是你自己的账号，适用它自己的条款和隐私政策。Speechless 没法在那里设置零保留。数据保留多久、会不会拿来训练、在哪里处理，由它的条款和你在那里的设置决定，不由 Speechless 决定。同意之前请先看：

  • OpenAI：隐私政策（英文）
  • 阿里云百炼（通义千问）：隐私说明、国际站的隐私说明（英文）
  • 火山方舟（豆包）：平台条款、隐私政策
  • 硅基流动：隐私政策、国际站的隐私政策（英文）
  • 你自己填地址的服务：请问运营它的人。

用这些服务时，让第二个模型再听一遍同一段录音是可选的。打开的话，录音也会发给那个模型。

按 App Store 的说法

在 App Store 上，Speechless 声明会收集“音频数据”和“其他用户内容”，与你的身份关联，用于 App 功能，不用于跟踪。这是因为它们会离开你的 iPhone，以你自己的账号发给你选的服务。我收不到这些内容。

我能收到什么

什么也收不到。我没有为 Speechless 设服务器，也不卖 AI 用量，所以录音、文字、Key 和使用数据都到不了我这里，我也不从这些服务拿任何数据。如果你给我写信，我会看到你的邮箱地址和信的内容，只用来回复你。

存在你的 iPhone 上的内容

  • API Key：每个服务一个，存在 iOS 钥匙串里，直到你更换或清除。每个 Key 只发给它所属的服务。
  • 设置和词典：直到你修改或清除。
  • 最近 30 条说过的内容：只有文字，更早的会自动去掉。
  • 录音：只留还没识别出来的句子，方便重试。识别出来之后、从列表里去掉时，或者你点“清空”时删除。
  • 技术日志：只有时间和错误信息，没有你说的话，留 14 天。只有你自己分享时才会离开手机。

Speechless 不会上传这些文件。如果你备份 iPhone，iOS 可能会把它们放进备份里，那是你和 Apple 之间的安排。

打字

ABC 键盘在手机上工作，不联网，也不需要完全访问。你用它打的字不保存、不记录、不发送。密码框里，iOS 会把第三方键盘换成自带的，所以那里用不到 Speechless。

“允许完全访问”和麦克风

打开“允许完全访问”之后，iOS 才给键盘网络和麦克风。语音这两样都需要，Speechless 打开它就是为了这个：说话时录音，发送上面列出的内容，以及让 App 和键盘共用设置、Key 和最近说过的内容。iOS 会提醒，有完全访问权限的键盘可能会把你打的字发给开发者。Speechless 不会这样做。不打开它，打字照常能用。

Speechless 只在你说话输入时录音，这时系统的麦克风指示和键盘自己的动画都会显示。一次最长 3 分钟；点一下开始的，一分钟没听到说话会自己停。不会在后台听。

撤回同意

你可以随时撤回同意，每个服务分开撤回：在 App 的“AI 服务”里点那个服务，再点“不再同意”。之后不会再往那里发送任何内容，打字照常能用。在那里删除一个服务，它的 Key 也会删掉。你也可以在 iOS 的设置里关掉 Speechless 的麦克风或完全访问。

删除数据

  • App 里的“清空”：删掉最近说过的内容，以及和它们一起留下的录音。
  • App 的“隐私”里的“清除全部数据”：删掉 Key、词典、设置、最近的内容、录音和日志，并撤回同意。
  • 删除 App 会一并删掉它存的内容，但 iOS 可能会在删除 App 之后保留钥匙串里的东西。请先点“清除全部数据”，把 Key 也删掉。你也可以到那个服务的账号里把 Key 删掉。
  • 各个服务已经处理过的数据，适用它们自己的政策；用 OpenRouter 时，零保留的服务不会留存。某个服务保留的和你有关的内容，请联系那个服务。

我手里没有来自 Speechless 的、关于你的数据，所以没有可以给你查看、更正或删除的内容。

跟踪、广告和出售数据

都没有。Speechless 不跨 App 或网站跟踪你，不放广告，不出售数据，也不为营销分享数据。

儿童

Speechless 不面向 13 岁以下的儿童。语音需要 AI 服务的账号，各个服务有自己的年龄要求；OpenRouter 的条款要求账号持有人是成年人。

在其他国家和地区处理

你选的服务可能在你所在的国家或地区之外处理你说的内容，那里的数据保护规定可能不一样。OpenRouter 和 OpenAI 是美国公司，OpenRouter 会把请求转给美国和其他国家的公司。阿里云百炼、火山方舟和硅基流动可能在中国处理；阿里云可以选北京或新加坡地域，硅基流动可以选中国站或国际站。你自己填地址的服务，取决于它在哪里。如果你不希望这样，就不要在 App 里同意那个服务：打字不受影响。

Mac 版

从本网站下载的 Mac 版使用同样的服务、遵守同样的规则：发送什么、发给谁、每个服务单独征求同意、OpenRouter 零保留，都和上面写的一样。不同的是：

  • 还会发送：你教过它的纠正，和识别出来的文字一起发，让整理模型照着写。针对某个词的，只在这个词又出现时发；通用的说明每次都发。
  • 辅助功能。macOS 会请你允许。Speechless 用它来识别快捷键、判断正在输入的是不是文本框，以及把文字粘贴进去。为了识别快捷键，系统会让它看到按键；它只找快捷键和 Esc，不记录、不发送任何按键。它不读取窗口里的内容。
  • 剪贴板。文字通过剪贴板粘贴，之后会留在剪贴板里，除非你打开「粘贴后恢复原来的剪贴板」。剪贴板管理工具和 Apple 的通用剪贴板能看到它。
  • 麦克风只在你说话时打开。点一下开始的录音，一分钟没听到说话会自动取消。
  • 存在你的 Mac 上：钥匙串里的 API Key；设置、词典和纠正；听写记录（文字、识别原文、时间、输入到哪个 App、用了哪些模型，以及服务商返回的费用）；最近的和失败的录音，方便重新识别。可以逐条删除，也可以在「设置 › 隐私 › 清除所有数据」里全部删除。
  • 没有技术日志，也不自动更新：它只连接你添加的服务。
